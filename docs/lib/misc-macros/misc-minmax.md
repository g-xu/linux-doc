# 杂项：min/max/clamp — 类型安全的比较宏

> B 级文档。内核自定义的 min/max 宏，比简单的三元表达式更安全。

## min/max/clamp — 类型安全的比较宏

### 定位

**功能**：提供类型安全的取最小值、最大值、范围限制操作。相比简单的三元表达式 `(a < b) ? a : b`，内核版本避免多次求值、检查有符号/无符号混合比较、处理小类型提升等常见陷阱。

**实现方式**：使用 `typeof` + 临时变量确保参数只求值一次（`x++` 安全）。通过 `__same_type` 在编译期检查两个参数类型是否兼容——有符号与无符号混合比较会触发编译错误。`unsigned char`/`unsigned short` 等小类型通过整数提升规则自动转为 `int`，可与有符号参数安全比较。`clamp` 系列用两次比较实现范围限制。

**应用场景**：全树 `min`/`max` 约 5 万+ 处、`clamp` 约 2000+ 处使用。遍布所有子系统：调度器（时间片限制）、网络（MSS/窗口大小钳位）、驱动（参数范围校验）、文件系统（块数/偏移量限制）等。是内核中最基础的值约束工具。

### 核心宏

| 宏 | 说明 |
|----|------|
| `min(x, y)` | 返回较小值，类型检查 |
| `max(x, y)` | 返回较大值，类型检查 |
| `min_t(type, x, y)` | 指定类型比较 |
| `max_t(type, x, y)` | 指定类型比较 |
| `clamp(val, lo, hi)` | 将值限制在 `[lo, hi]` 范围内 |
| `clamp_t(type, val, lo, hi)` | 指定类型的 clamp |
| `clamp_val(val, lo, hi)` | 常量版本的 clamp |
| `min3(x, y, z)` | 三值取最小 |
| `max3(x, y, z)` | 三值取最大 |

### 设计要点

`minmax.h:10-22` 注释说明了三个要求：

1. **避免多次求值**：`x++` 只执行一次（使用 `typeof` + 临时变量）
2. **有符号/无符号类型检查**：混合类型比较产生编译错误
3. **小类型提升**：`unsigned char/short` 提升为 `int` 后可与有符号参数比较

### 使用示例

```c
int len = min(remaining, PAGE_SIZE);        // 两者类型必须兼容
unsigned int val = min_t(unsigned, a, b);   // 强制类型
int clamped = clamp(user_val, 0, 100);      // 限制在 [0, 100]
```

### 使用统计

`min`/`max` 在全树出现约 **5 万+** 次，`clamp` 约 **2000+** 次。
