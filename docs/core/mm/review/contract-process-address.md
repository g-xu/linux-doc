# 进程地址空间：写前约定

本地 Linux 6.1.158、arm64、RT补丁分析前提，配置未知保留条件。只重写本篇及必要独立SVG，操作边界同[本轮队列](completion-mm-series.md)。

| 任务 | 应能完成的判断 |
| --- | --- |
| Q0 | 区分地址空间对象mm、VMA范围语义、页表转换与实际后备，不把mmap等同于逐页分配。 |
| Q1 | 解释任务共享或复制mm，区分mm_users和mm_count，并推演最后使用者退出而对象仍被持有。 |
| Q2 | 用同一文件映射[4,12)→相邻扩展到16→中间权限变化→解除[9,11)推演边界、map_count、文件页偏移。 |
| Q3 | 对最终范围推演包含、后继、end边界与空洞；解释半开VMA转Maple闭区间。 |
| Q4 | 区分可合并条件、局部拆分和实际映射变化，不能仅凭相邻权限相同就合并。 |
| Q5 | 解释mmap/mprotect/munmap的阶段资源、布局锁、页表保护和失败副作用；包含一处具体失败后仍已拆分的源码例。 |
| Q6 | 正确取得mm和查询VMA，复制值后放锁/引用，不把mmgrab或Maple Tree RCU当作指针使用权限。 |
| Q7 | 解释用户API与内核内部接口、原始返回和libc错误约定、完整资源清理和MAP_FIXED风险。 |
| Q8 | 区分范围大小、RSS、物理共享、文件私有COW、堆/栈用途和退出后备寿命，并找到源码。 |

图计划：任务/mm/VMA/页表关系、同一文件映射的三次变化、mm引用寿命。P为实际基本页大小，B为合法用户地址窗口的示意基址，图中的数字是窗口内虚拟页偏移，不是PFN或固定arm64地址。
