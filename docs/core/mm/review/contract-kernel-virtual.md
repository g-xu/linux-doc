- 不固定页大小、VA 位宽、芯片、实际 vmalloc 地址界限。基本页映射作为主模型，大映射、检测和权限重置按条件区分。

- 内核源码只读，不编译或运行内核，不加载模块、改配置、调参、压力实验、部署、提交或推送。

## 连续场景与配图

- 主映射：三页虚拟范围，依次映射 PFN 4、19、8；偏移跨页不改变页内偏移规则。
- 大小与区间：请求三基本页，普通 guard 占一页地址空间；页数组是另占管理内存，不是数据副本。虚拟页号仅为示意偏移，不是合法 arm64 绝对地址。
- 分配：保留范围，再准备页数组、取得后备和建立映射；普通 vmap 复用同一页序列，但所有权不同。
- 失败：准备部分页或部分 PTE 后失败，不交付部分成功指针；清理已取得资源，VA 可能等待 lazy 回流。
- 释放：调用者先停止访问；页表清除与旧 TLB 不同，后备归还与地址区间复用不同；lazy purge 前旧范围不能映射为冲突的新后备。
- SVG：基本映射关系、范围切分、资源/流程、所有权、lazy 时序。图仅画必要机制，先定义概念再引入复杂管理图。
