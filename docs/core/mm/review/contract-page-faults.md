# 缺页与COW：写前约定

基线本地Linux6.1.158、arm64、RT补丁，普通用户基本页例子；大页、KSM、用户缺页代理等条件化，不执行故意异常或压力实验。边界同[完成队列](completion-mm-series.md)。

| 任务 | 应能完成的判断 |
| --- | --- |
| Q0 | 区分TLB miss、CPU异常、合法按需缺页、非法访问和来源/资源失败，不把缺页当必然I/O/分配。 |
| Q1 | 沿同一匿名页读零页→写P→普通fork共享P→子写Q，跟踪PTE、私有后备和共享关系，区分RSS/物理数量。 |
| Q2 | 根据VMA权限、匿名/文件来源、PTE none/swap/present写保护选择路径，区分私有COW与共享写。 |
| Q3 | 区分已AnonExclusive直接复用与非独占保守检查；父退出/额外引用不作为统一复制或复用条件。 |
| Q4 | 准备页/收费/复制、锁下重检、清旧/安装/结束引用或放弃；至少一个他人先安装及收费失败的完整推演。 |
| Q5 | 普通arm64入口的COMPLETED/RETRY/其他结果锁责任，信号及RETRY_NOWAIT边界，重试需新查询。 |
| Q6 | 解释回调/返回位、执行上下文、页锁与布局锁区别，不造模块直接补任意地址API。 |
| Q7 | 根据错误来源判断OOM/SIGBUS/权限处理不同；解释minor/major实际计数与访问成功不等于永久无缺页。 |
