### C1：PCP 与水位口径的衔接

**挑战者观点：** 第 3.5/3.6 节没有说明 `NR_FREE_PAGES` 与 PCP `count` 的关系，也没有明确一般高阶水位检查扫描 Buddy `free_area` 而非 PCP。读者无法推演“PCP 已有匹配块，为什么首次检查仍跳过 Zone”。

**依据：** `rmqueue_bulk()` 从 Buddy 补充 PCP 时扣除区域空闲统计；局部取用更新 PCP count；`__zone_watermark_ok()` 检查 Buddy 高阶列表；`get_page_from_freelist()` 在调用 `rmqueue()` 前检查水位。入口为 [page_alloc.c](../../../../../linux-6.1.158/mm/page_alloc.c)。

**作者回应：接受。** 独立核对上述实现后，补充四种资源转移的统计表，以及 Buddy 100 页仅有低阶碎片、PCP 有匹配 order-2 块但不能绕过高阶检查的反例。排空后为 104 页并出现高阶候选，明确不承诺每次失败都立即排空；新增图 6a。

**修订位置：** [第 3.5 节](../01-page-allocation.md#pcp)、[第 3.6 节](../01-page-allocation.md#watermarks)、`images/page-allocation/06a-pcp-gate.svg`。

**作者验证：** 数量与转移计算、Markdown 与 SVG 解析、浏览器渲染和文字/连线边界已检查；没有运行目标机或内核实验。

**复核状态：resolved。** Pauli 回读修改和图 6a 后确认：统计转移、检查顺序及 100/104 页反例与目标源码一致，简化边界保留充分。

### C2：位置候选缺少可推演的筛选规则

**挑战者观点：** “最高 Zone”“位置检查”等名称没有解释上界、搜索顺序及节点筛选。读者不能判断单加 `__GFP_MOVABLE` 是否进入 MOVABLE Zone，或首选节点失败后哪些候选仍合法。

**依据：** [gfp.h](../../../../../linux-6.1.158/include/linux/gfp.h) 中的 `gfp_zone()` 与 `gfp_zonelist()`；[mmzone.c](../../../../../linux-6.1.158/mm/mmzone.c) 的区域上界与 nodemask 迭代筛选。

**作者回应：接受。** 新增第 2.3 节，区分 zonelist 顺序、Zone 索引上界与允许节点；用假设存在的两节点/三类区域说明筛选。对比 GFP_KERNEL、附加 MOVABLE、HIGHUSER_MOVABLE 的上界与类型，区分首选节点与 THISNODE；不沿用其他架构的地址常量，不把普通约束推广到所有保留覆盖。

**修订位置：** [第 2 节](../01-page-allocation.md#organization)的 2.3、新增 `images/page-allocation/02a-candidates.svg`；原始入口表 A2 补充 mmzone.c。

**作者验证：** 区域表与候选实现、链接/锚点和新增图的实际渲染已核对。

**复核状态：resolved。** Pauli 确认第 2.3 节的顺序、索引上界、节点筛选、三种 GFP 和 THISNODE 说明可推演，图 2a 没有将假设区域变成平台事实。

### C3：迁移类型回退与分类变化不能推演

**挑战者观点：** 第 3.4 节没有普通类型回退顺序，未区分本类型的小阶向上查找与回退的大阶向下查找，也未区分当前空闲列表与 pageblock 标记变化。

**依据：** [page_alloc.c](../../../../../linux-6.1.158/mm/page_alloc.c) 的 `fallbacks`、`find_suitable_fallback()`、`__rmqueue_fallback()`、`steal_suitable_fallback()`。

**作者回应：接受。** 补回退顺序表，以及 UNMOVABLE order-1 在较小 RECLAIMABLE 块和较大 MOVABLE 块间选择后者的缩小模型。明确先看阶数，再看该阶类型；整 pageblock 接管时标记和列表都更新，随后按本类型拆分。分清小候选只改列表和条件满足才改 pageblock 的情况；说明 MOVABLE 的 can_steal=false 分支发生在候选选择时。模型显式排除特殊类别、NOFRAGMENT、PCP 和并发。

**修订位置：** [第 3.4 节](../01-page-allocation.md#mobility)、新增 `images/page-allocation/04a-type-fallback.svg`。

**作者验证：** 独立阅读回退与接管实现、检查 PFN 区间守恒、表格/链接与新增图渲染。

**复核状态：resolved。** Pauli 确认普通类型顺序、大阶优先、MOVABLE 例外与两类状态变化已经补足，缩小模型的块选择、接管、拆分及图 4a 与目标实现一致。
