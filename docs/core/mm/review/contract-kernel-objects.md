## 模型、实例和配图计划

- 数量主线：四槽位 A/B/C/D 的同一 slab，明确不代表真实页大小、对象容量或 freelist 地址顺序。
- 主过程：建立、CPU0 激活、分配 A/B、CPU1 归还 A、CPU0 继续取 C/D、回收共享 A、停用并保留 B。
- 对照分支：停用前后 B 归还，节点 partial 数量改变空 slab 留存；远程释放在停用 CAS 之前发生导致重读重算。
- 布局实例另用明确假设的页大小与对象尺寸，不与四槽位抽象混为真实配置。
- 专用 SVG：供给与对象关系、槽位布局、双 freelist 状态、分配路径、停用竞争。使用状态表补足精确计数，不用图示代替解释。
- 源码：`mm/slub.c`、`mm/slab_common.c`、`mm/slab.h`、`include/linux/slub_def.h`、`include/linux/slab.h`，必要时追踪 arm64 原子实现与本地锁定义。
