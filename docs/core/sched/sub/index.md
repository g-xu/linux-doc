# 调度深入专题：从架构位置选择阅读路径

[总览](../00-overview.md#architecture)说明整个调度器怎样组成，本目录把其中的对象、协议、策略和决策展开。**专题不是源码文件的同义词**：等待协议跨越同步与调度代码，`fair.c` 则同时实现公平策略、带宽和多核均衡。

统一基线：Linux 6.1.158-rt58、arm64、`PREEMPT_RT=y`。各篇按自身性质组织：对象先讲组织与生命周期；策略先讲模型再走完整运行循环；协议先走正常交接再解释竞态；信号先固定时钟和单位；观察先拆现象再找证据。

<a id="route"></a>

## 1. 核心执行：谁参与，怎样进入，怎样交接？

建议顺序：任务/rq → 等待唤醒 → 调度切换。它们建立所有调度类共用的状态基础。

| 专题 | 类型 | 主要问题 |
| --- | --- | --- |
| [任务与 rq](core/01-task-rq.md) | 对象 | 任务、类实体、当前任务与各类成员怎样组织？谁负责存活和保护？ |
| [等待与唤醒](core/02-wait-wakeup.md) | 协议 | 条件发布怎样接上睡眠/唤醒？退队前后有哪些竞态？ |
| [调度核心与 arm64 切换](core/03-schedule-switch.md) | 协议 | 一次 A→B 怎样经过选择、mm、寄存器/栈和旧任务收尾？ |

## 2. 服务策略：一颗 CPU 上怎样分配执行？

三类策略可以分别阅读。都沿“目标与模型 → 状态对象 → 入队/选择/记账/退出/恢复 → 变体”展开；学完一类后可以比较另两类把共同循环中的哪些规则换掉。

| 专题 | 主要模型 | 重点 |
| --- | --- | --- |
| [CFS](fair/01-cfs.md) | 带权服务进度 | vruntime、current/树、粒度，随后加入睡眠、迁移坐标和任务组 |
| [FIFO/RR](realtime/01-fifo-rr.md) | 固定优先级 | 位图/链表，同级执行循环、RR 剩余计数、带宽与多核协调 |
| [Deadline](realtime/02-deadline.md) | EDF + CBS | Q/D/P 与 q/d、预算耗尽/补充、唤醒规则、准入及 GRUB |

stop 和 idle 的职责见[总览的调度类](../00-overview.md#architecture)，目前不另开文章。
