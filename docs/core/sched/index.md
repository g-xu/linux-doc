# Linux 内核调度

调度器把任务的运行需求转换成实际的 CPU 执行：维护运行资格，按策略分配时间，在多核之间放置任务，并与睡眠、唤醒和上下文切换协作。

基线为 **本地 Linux 6.1.158、arm64、已打 RT 补丁，假定 `PREEMPT_RT=y`**。先建立整体认识，再按问题深入；接口查询不要求先读完所有机制。
